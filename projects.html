CivilTech Concrete Calculator

Civil EngineeringHTML/CSS/JS

The problem

On a construction site, working out how much sand, gravel, and cement a job needs is normally done by hand, using mix ratios and volume calculations. A small error in that math can mean ordering the wrong quantity of material, which costs time and money.

What it does

You enter the volume of concrete you need and your target mix ratio. The calculator works out the exact quantities of sand, gravel, and cement required to meet that volume and the loading limits the mix is meant to satisfy.

How it works

It takes your inputs, applies the standard volume-ratio formulas used in concrete mix design, and returns each material quantity. Everything runs in the browser — no server needed.

Use case

A student or small contractor estimating materials for a slab or footing before ordering supplies.

AI Engineering Translation App

Full-StackPython / FlaskGemini API

The problem

Technical and industrial documentation is often written in dense, field-specific language that's hard to translate accurately with general-purpose tools.

What it does

It translates heavy, niche industrial documentation in near real time, aiming for translation speeds under two seconds per request.

How it works

A Flask backend receives the document text and passes it through a Google Gemini 3.6 Flash API pipeline for translation, then returns the result to a responsive web interface. The backend is hosted on Render's cloud server architecture, and I also built a standalone wrapper for mobile distribution.

Use case

An engineer needing a fast, field-specific translation of a technical manual or spec sheet.

To-Do List App

JavaScript

What it does

A task management tool where you can add, track, and remove tasks instantly, with no page reloads.

Why I built it

To practice JavaScript's event delegation pattern — handling clicks on dynamically created elements — and DOM manipulation without a framework.

How it works

New tasks are inserted into the page as DOM elements on the fly; a single event listener on the parent list handles add, complete, and delete actions for every task, even ones created after the page loaded.
